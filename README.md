# 🐶 PawFect Match – Pet Adoption System

Full-stack project using **FastAPI**, **React (Vite)**, **Tailwind CSS**, and **MySQL (Aiven)**.

---

## 🔧 Tech Stack

### Backend
- FastAPI  
- SQLAlchemy ORM  
- PyMySQL  
- Uvicorn  
- Python Dotenv  

### Frontend
- React + Vite  
- Tailwind CSS  

### Database
- MySQL (Aiven)

---

## ⚙️ Backend Setup

### 1. Create virtual environment
```bash
cd backend
python -m venv venv
venv\Scripts\activate   # Windows
# or
source venv/bin/activate  # Mac/Linux
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. run backend
```bash
uvicorn app.main:app --reload
```
